# Would You Merge This PR?

An interactive simulation of a backend engineer's work week. Friday-evening merges, production incidents, legacy CoffeeScript, impossible deadlines: every decision quietly affects your score across Technical Judgment, Risk Management, Team Collaboration and Production Survival.

**Play it:** https://jmromera.github.io/would-you-merge-this-pr/

## Stack

React · TypeScript · Vite · Tailwind CSS · Framer Motion

## Run locally

```bash
npm install
npm run dev     # dev server
npm test        # unit tests
npm run build   # production build
```

## Deployment

Every push to `main` is tested, built and deployed to GitHub Pages by [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
